📸 Instagram API Setup

To enable auto-posting to Instagram, enter your Instagram Graph API credentials below.

How to get your Instagram credentials:
1. Go to developers.facebook.com
2. Create an App → Add Instagram Product
3. Connect your Instagram Business Account
4. Generate a Long-lived Access Token
5. Get your Instagram User ID from the API
6. Get free imgbb key at api.imgbb.com

Note: Your Instagram account must be a Business or Creator account connected to a Facebook Page.

🔄 Backup & Sync Between Devices

All ToonCakes data (orders, menus, classes, recipes, reviews, settings) is saved in this browser only. To use it on another browser or device, export a backup here and restore it there.

📤 Export Complete Backup

Downloads a single .json file containing everything — orders, menus, reviews, classes, recipes, coupons, posts and settings.

📥 Restore from Backup

Select the .json backup file exported from your other device. All data will be restored and the page will reload.

💡 Tip: Export a backup every time you make big changes (add menus, process orders). Save the file in Google Drive so you can access it from any device instantly.
